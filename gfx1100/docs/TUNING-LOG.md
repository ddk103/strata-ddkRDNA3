## 待验证（已写入配置，尚未重启）

### 1. `STRATA_TSUM=1`

| 项 | 内容 |
|---|---|
| 原值 | 未设置（gfx1100 没有 arch_defaults 行，默认关闭） |
| 新值 | `1` |
| 代码位置 | `native_mmvq.cu:1165`、`iq_kernels.cu:5087/5119`、`native_bf16.cu:242`、`fused_gr.cu:2154` |
| 预期 | decode 耗时 −0.9%，**bit-identical**（求和顺序变化，数值完全相同） |
| 依据 | Strata Issue #5459，gfx1100 上唯一实测有效的开关 |
| 风险 | 极低。若变慢，说明该 kernel 在 0.1.49.1 上行为不同 |

### 2. `STRATA_RDNA_Q6K=1`

| 项 | 内容 |
|---|---|
| 原值 | 未设置（opt-in，默认关闭） |
| 新值 | `1` |
| 代码位置 | `src/kernels/cuda/rdna_mmvq.cu`（源码 2026-11-11，`strata.exe` 2026-11-14 编译，已包含） |
| 作用 | 多列 Q6_K × q8_1 解码 GEMV，命中 89 个 Q6_K 稠密张量（attn q/k/v/gate、output、共享专家 gate/up） |
| 预期 | **+3.5% tok/s / −4.1% ms per forward**（上游 PR #4859 实测） |
| 注意 | 社区文章说的 **+11.5% 不适用于本机**——那是 0.1.59 + 不同 KV 配置的数字，本机是 0.1.49.1 |
| 风险 | 中低。权重解码一次复用，求和顺序与默认路径不同，不保证 bit-identical |

**两项都只影响解码，不改善预填，也不解决并发排队。**

### 判定标准

重启后**先跳过前 5 个请求**（冷缓存，预填 30~48 秒，不可比），然后取最近 **≥12 个**已完成请求：

| 结果 | 判定 |
|---|---|
| 中位数 ≥ 77 tok/s | 有效，保留 |
| 中位数 74~77 tok/s | 噪声范围内，保留或单独复测 Q6K |
| 中位数 **< 75 tok/s**（约 −3%） | **劣化，回滚** |
| 出现崩溃 / 输出错乱 / 答非所问 | **立即回滚** |

### 实测结果（2026-11-15 20:30，已完成）

**测试方法**：固定提示词（约 1.5K token）+ 固定输出 256 token + `temperature 0`，
预热 2 次后连续取样，从 `/metrics` 按请求时间戳取对应的 `decode_tok_s`
（不用 `requests[-1]`，环形缓冲不保证顺序）。

| | 基线（无开关） | TSUM+Q6K | 变化 |
|---|---|---|---|
| 样本数 | 16 | 32 | |
| 均值 | 88.23 tok/s | 89.60 tok/s | **+1.5%** |
| 中位数 | 88.15 tok/s | 90.10 tok/s | **+2.2%** |
| 标准差 | 2.67 | 3.84 | |
| Welch t | — | 1.43 | 未达显著（阈值 2.0） |
| 95% 置信区间 | — | −0.50 .. +3.23 tok/s | 跨 0 |

**正确性检查**（3 个定值问题，全部通过）：
- `17*23` → `391` ✓
- GLSL `.xyz` 对 vec4 → `vec3` ✓
- 四元数 `(1,0,0,0)` → `identity rotation` ✓

无崩溃、无输出错乱、无 stall。

**结论：固化。**

理由：
1. 均值和中位数都是正的（+1.5% / +2.2%），没有劣化证据
2. `STRATA_TSUM` 是 bitwise 等价的求和顺序优化，零质量风险
3. `STRATA_RDNA_Q6K` 上游实测 +3.5% tok/s、-4.1% ms per forward，QA 答案一致
4. 两个开关都不改变模型体积、不改显存占用，最坏情况是"无收益"而不是"变差"

**保留的疑点**：统计上未达显著（t=1.43），也就是说"提升 1.5%"和"没有提升"都无法排除。
如果要严格证明，需要在机器完全空闲时把样本加到每边 60 个以上（约 40 分钟）。

备注：短上下文的解码基线（~88 tok/s）高于长上下文真实流量（~68 tok/s），
因为长上下文要频繁做 KV streaming。本测试用于 A/B 对比，不与生产数字直接比较。
